물리 검증 반복 실행 안내 (Windows) — M5-repeat-01

목적: pilot-02c에서 H0 버전이 바닥을 뚫고 떨어진 현상이 다시 나오는지 확인합니다.

준비물: 이 ZIP 하나. Unity, Python, Git, 관리자 권한은 필요 없습니다.

1. ZIP 전체를 바탕화면 등 쓰기 가능한 폴더에 압축 해제합니다. (ZIP 안에서 바로 실행하지 마세요)
2. RunRepeat01.cmd 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다. (서명되지 않은 테스트 프로그램이라 뜨는 경고입니다)
   - 방화벽 허용 창이 뜨면 취소해도 됩니다. 네트워크는 쓰지 않습니다.
3. 게임 창이 16번 열립니다. 합계 약 40분입니다.
   - 처음 6번은 각 5~6분(같은 테스트 53개를 순서만 바꿔 반복)
   - 나머지 10번은 각 30초 안팎(한 지점에 가만히 서 있는 테스트 1개, 일부는 30·120fps)
   - 창을 최소화하지 말고, 실행 중에는 마우스를 움직이지 마세요. 개미 방향에 영향을 줄 수 있습니다.
   - 중간에 멈춰야 하면 창 왼쪽 위 "Stop (save & quit)" 버튼을 누르세요. 끝난 부분까지 저장됩니다.
4. 마지막에 "Done" 메시지와 함께 PhysicsBench-Repeat01-Results-날짜.zip 파일이 생깁니다. 이 ZIP을 보내 주세요.
   - ZIP이 없으면 Results 폴더(또는 안내된 폴더)를 통째로 보내 주세요.

가능하면 두 PC(i5-12500 데스크톱과 i9 노트북)에서 각각 한 번씩 실행해 주세요. 결과 ZIP 이름이 실행 시각으로 달라서 섞이지 않습니다.
한 PC에서만 실행해도 분석할 수 있습니다.

결과 ZIP에는 실행 기록(위치·속도 등 수치), Unity 로그, PC 사양(OS·CPU·GPU 이름과 드라이버 버전, PC 모델명)이 들어 있습니다. 개인 파일은 포함하지 않습니다.
