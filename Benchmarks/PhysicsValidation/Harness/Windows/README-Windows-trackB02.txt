물리 검증 트랙 B-02 실행 안내 (Windows) — M5-trackB-02

목적: 연석 관통 원인 가설을 테스트용 빌드(연석 콜라이더 밑면을 늘린 버전)로 확인합니다. 실제 게임은 바뀌지 않습니다.

1. trackB-01을 먼저 실행한 같은 PC에서, 이 ZIP을 쓰기 가능한 폴더에 압축 해제합니다.
2. RunTrackB02.cmd 를 더블클릭합니다. ("Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행])
3. 게임 창이 6번 열립니다. 합계 약 15분입니다. 창을 최소화하지 말고, 실행 중에는 마우스를 움직이지 마세요.
4. 마지막에 PhysicsBench-TrackB02-Results-날짜.zip 파일이 생깁니다. 이 ZIP을 보내 주세요.

결과 ZIP에는 실행 기록(위치·속도 등 수치), Unity 로그, PC 사양이 들어 있습니다. 개인 파일은 포함하지 않습니다.
