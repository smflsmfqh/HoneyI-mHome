물리 검증 pilot 실행 안내 (Windows) — M5-pilot-02c

준비물: 이 ZIP 하나. Unity, Python, Git, 관리자 권한은 필요 없습니다.

1. ZIP 전체를 바탕화면 등 쓰기 가능한 폴더에 압축 해제합니다. (ZIP 안에서 바로 실행하지 마세요)
2. RunPilot02c.cmd 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다. (서명되지 않은 테스트 프로그램이라 뜨는 경고입니다)
   - 방화벽 허용 창이 뜨면 취소해도 됩니다. 네트워크는 쓰지 않습니다.
3. 게임 창이 여섯 번(Hm1, Hm1-통제80, Hm1-통제112, H0, H1, H7 순서) 열리고 개미가 자동으로 움직입니다. 합계 약 110분입니다(Hm1 창 3개는 각 12~15분, 나머지 창은 각 18~21분). 긴 직선 보행 case가 있어 한 장면이 40초 넘게 이어질 수 있습니다.
   - 키보드·마우스 입력은 테스트에 들어가지 않지만, 창을 최소화하지 말고 그대로 두세요.
   - 특히 처음 세 개(Hm1 계열) 창이 떠 있는 동안에는 마우스를 움직이지 마세요. 이 버전은 실제 마우스 움직임으로 개미 방향이 바뀝니다.
   - 중간에 멈춰야 하면 창 왼쪽 위 "Stop (save & quit)" 버튼을 누르세요. 끝난 부분까지 저장됩니다.
4. 마지막에 "Done" 메시지와 함께 PhysicsBench-Pilot02c-Results-날짜.zip 파일이 생깁니다. 이 ZIP을 보내 주세요.
   - ZIP이 없으면 Results 폴더(또는 안내된 폴더)를 통째로 보내 주세요.

결과 ZIP에는 실행 기록(위치·속도 등 수치), 화면 캡처, Unity 로그, PC 사양(OS·CPU·GPU 이름과 드라이버 버전)이 들어 있습니다. 개인 파일은 포함하지 않습니다.
