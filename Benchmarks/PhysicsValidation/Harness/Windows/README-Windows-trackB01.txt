물리 검증 트랙 B 실행 안내 (Windows) — M5-trackB-01

목적: 바닥 콜라이더 구성(Mesh·받침판·Convex·Box)과 물리 설정을 바꿔 가며, 각 수정 단계가 무엇을 고쳤는지 확인합니다.

준비물: 이 ZIP 하나. Unity, Python, Git, 관리자 권한은 필요 없습니다.

1. ZIP 전체를 바탕화면 등 쓰기 가능한 폴더에 압축 해제합니다. (ZIP 안에서 바로 실행하지 마세요)
2. RunTrackB01.cmd 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
   - 방화벽 허용 창이 뜨면 취소해도 됩니다. 네트워크는 쓰지 않습니다.
3. 게임 창이 30번 열립니다. 합계 약 80분입니다.
   - 처음 18번: 바닥 구성 6종 × 3회 (각 2~4분. 일부 구성은 개미가 바닥 아래로 떨어지는 것이 정상입니다)
   - 나머지 12번: 연석 돌진 테스트, 물리 설정 4종 × 3회 (각 2분 안팎)
   - 창을 최소화하지 말고, 실행 중에는 마우스를 움직이지 마세요.
   - 중간에 멈춰야 하면 창 왼쪽 위 "Stop (save & quit)" 버튼을 누르세요. 끝난 부분까지 저장됩니다.
4. 마지막에 PhysicsBench-TrackB01-Results-날짜.zip 파일이 생깁니다. 이 ZIP을 보내 주세요.

repeat-01과 같은 PC에서 이어서 실행해도 됩니다. 결과 ZIP 이름이 달라 섞이지 않습니다.
결과 ZIP에는 실행 기록(위치·속도 등 수치), Unity 로그, PC 사양(OS·CPU·GPU 이름과 드라이버, PC 모델명)이 들어 있습니다. 개인 파일은 포함하지 않습니다.
